## Overview
Kortex Flow chains Kortex tools: a starting text, then tools connected to each other, each receiving the previous result. A workflow is a small versioned JSON file you can export and import.
## Usage
Add a text and one or more tools, choose for each input the step that provides it, set the parameters, then run. Flow checks port types and refuses loops before starting anything. In the desktop app each installed tool runs on your computer; on the web you build, export and import workflows.
## Frequently asked questions
### Does my data leave my device?
No. Steps run locally with the installed tools; the workflow only stores its structure and your texts in your device's storage.
### Why can't I run in the browser?
Tool engines are not served to this application yet. Running is therefore offered on desktop, with the tools you installed.
### Which tools can I use?
This version offers tools whose required inputs are text. Tools that need files will come with file nodes.
