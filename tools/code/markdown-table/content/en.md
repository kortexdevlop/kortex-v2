## About

Paste a tab-separated spreadsheet table or simple delimited data. Pipes are escaped and HTML tags are neutralized.

## How to use this tool

1. Enter values or paste your text.
2. Choose the relevant options and run the tool.
3. Read and copy the result.

## Frequently asked questions

### What example can I try?

“Name [tab] Age” then “Ada [tab] 36” produces a header and one row.

### What are the limitations?

No CSV quoting or multiline cells. Every row must have the same width. Other Markdown syntax remains active.

### Is my data uploaded?

No. Processing stays on your device without an account or network transmission.
