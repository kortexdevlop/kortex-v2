## À propos

Collez un tableau depuis un tableur avec des tabulations, ou des données délimitées simples. Les barres verticales sont échappées et les balises HTML sont neutralisées.

## Comment utiliser cet outil

1. Saisissez les valeurs ou collez votre texte.
2. Réglez les options utiles, puis lancez le traitement.
3. Consultez le résultat et copiez-le.

## Questions fréquentes

### Quel exemple puis-je essayer ?

« Nom [tab] Âge » puis « Ada [tab] 36 » produit un en-tête et une ligne.

### Quelles sont les limites ?

Pas de guillemets CSV ni de cellules multilignes. Toutes les lignes doivent avoir la même largeur. Les autres syntaxes Markdown restent actives.

### Mes données sont-elles envoyées ?

Non. Le traitement reste sur votre appareil, sans compte ni transmission réseau.
