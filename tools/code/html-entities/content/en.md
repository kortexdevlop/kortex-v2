## About

Escape &, <, > and quotation marks for inserting text into HTML source. Decoding recognizes amp, lt, gt, quot, apos, nbsp and decimal or hexadecimal numeric references.

## How to use this tool

1. Enter values or paste your text.
2. Choose the relevant options and run the tool.
3. Read and copy the result.

## Frequently asked questions

### What example can I try?

<hello> becomes &lt;hello&gt;; &#x1F600; decodes to an emoji.

### What are the limitations?

Single-pass decoding requires semicolons. Other names, such as copy, remain unchanged. This is not an HTML, JavaScript or URL sanitizer.

### Is my data uploaded?

No. Processing stays on your device without an account or network transmission.
