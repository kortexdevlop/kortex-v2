## À propos

Échappez &, <, > et les guillemets pour insérer du texte dans une source HTML. Le décodage reconnaît amp, lt, gt, quot, apos, nbsp et les références numériques décimales ou hexadécimales.

## Comment utiliser cet outil

1. Saisissez les valeurs ou collez votre texte.
2. Réglez les options utiles, puis lancez le traitement.
3. Consultez le résultat et copiez-le.

## Questions fréquentes

### Quel exemple puis-je essayer ?

<bonjour> devient &lt;bonjour&gt; ; &#x1F600; donne un emoji lors du décodage.

### Quelles sont les limites ?

Décodage en une passe, point-virgule obligatoire. Les autres noms, comme copy, restent inchangés. Ce n’est pas un assainisseur HTML, JavaScript ou URL.

### Mes données sont-elles envoyées ?

Non. Le traitement reste sur votre appareil, sans compte ni transmission réseau.
