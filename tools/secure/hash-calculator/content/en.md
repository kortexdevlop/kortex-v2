## Compute the fingerprint of a file or text
A hash is a digital fingerprint: change a single byte and the fingerprint changes completely. This tool computes MD5, SHA-1, SHA-256 and SHA-512 right on your device. Your file is never uploaded.

## How it works
1. Drop a file (or type some text).
2. Pick the algorithm (SHA-256 is recommended).
3. Copy the hash, or paste the expected hash to verify a download.

## FAQ
### Is my file sent over the internet?
No. The computation happens locally, with no network request.
### Which algorithm should I choose?
SHA-256 to check a file's integrity. MD5 and SHA-1 are no longer safe against an attacker but remain common for simple checksums.
### How do I verify a download?
In Pro mode, paste the hash published by the vendor into "Compare with": the tool tells you whether they match.
