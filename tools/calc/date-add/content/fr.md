## À propos

Décalez une date en jours calendaires ou du lundi au vendredi. Le calendrier grégorien est utilisé pour toutes les années.

## Comment utiliser cet outil

1. Saisissez les valeurs ou collez votre texte.
2. Réglez les options utiles, puis lancez le traitement.
3. Consultez le résultat et copiez-le.

## Questions fréquentes

### Quel exemple puis-je essayer ?

Le 28 février 2024 plus un jour donne le 29 février.

### Quelles sont les limites ?

Le mode lundi–vendredi exclut les week-ends mais ne connaît pas les jours fériés. Le jour de départ n’est pas compté. Dates de 0001 à 9999.

### Mes données sont-elles envoyées ?

Non. Le traitement reste sur votre appareil, sans compte ni transmission réseau.
