## Créer un QR code gratuit, sans compte
Collez un lien ou un texte, choisissez le format, téléchargez. Le QR code est généré sur votre appareil : le contenu n'est jamais envoyé sur Internet, et il n'expire jamais (c'est un QR code statique).

## Comment ça marche
1. Saisissez le lien ou le texte à encoder.
2. Choisissez PNG (images, impression) ou SVG (vectoriel, taille libre).
3. Cliquez sur Lancer puis téléchargez l'image.

## FAQ
### Le QR code expire-t-il ?
Non. Le contenu est inscrit directement dans l'image : aucun service ne peut le désactiver.
### Quel format choisir ?
PNG pour le web et les messageries, SVG pour l'impression en grand format sans perte de qualité.
### Puis-je changer les couleurs ?
Oui, en mode Medium. Gardez un fort contraste entre les modules et le fond pour que le QR code reste lisible.
