# 0027 — Nœud Agent IA de Flow
**Statut** : accepté (2026-10-19), demande de l'utilisateur (« un nœud appelé agent, une source, un prompt, une sortie texte/JSON/tableau, plein de fonctionnalités IA », comme n8n ou Make). S'appuie sur ADR 0023 (Gemma, protocole par références) et ADR 0026 (nœuds hôte).
**Décision** :
- **Nœud** `Logic` op `ai` (job hôte `flow.ai`) : entrées optionnelles `source` et `context` (texte, typiquement la sortie du nœud précédent), paramètres `task` (consigne libre, résumer, traduire, classer, extraire des champs, sentiment, réécrire, corriger, mots-clés), `prompt`, `format` (texte, JSON, tableau, liste), `fields` (catégories, champs ou colonnes), `language`, `tools`, `max_steps` ; sorties `text` et `table`. Une branche amont ignorée ignore le nœud.
- **Logique pure** dans `kortex_ai::agent` : construction des messages (la source et le contexte entre `<source>`/`<context>`, présentés au modèle comme des **données**, balise fermante neutralisée), lecture des réponses (JSON extrait d'un bloc de code ou d'un texte, tableau d'objets ou de listes avec colonnes imposées ou déduites dans l'ordre d'apparition, liste sans puces), **une seule réparation** si le JSON est invalide, boucle d'outils bornée (6 étapes). Sans réseau : testée avec un modèle scripté.
- **Outils locaux** (mode agent) : le modèle désigne les données par références (`@texte1` source, `@texte2` contexte, `@cN.text`), comme dans Mind ; les références laissées dans la réponse finale sont remplacées par les vraies valeurs, y compris un nom de sortie traduit par le modèle. Seuls les outils cochés sur le nœud ET sûrs sans confirmation humaine sont exécutables (une entrée texte, une sortie texte, ni réseau, ni écriture de fichier, ni donnée sensible).
- **Transport partagé** : le client de la passerelle (flux SSE, session du navigateur, jeton d'appareil sur ordinateur) devient la crate `kortex-ai-client`, utilisée par Mind et Flow.
- **Consentement et crédits** : le texte des nœuds Agent n'est envoyé qu'après acceptation explicite (mémorisée sur l'appareil, vérifiée par l'interface et par l'hôte) ; jamais de fichier ni de secret. Compte requis ; crédits affichés en pourcentage ; erreurs de la passerelle traduites.
- **Passerelle** : la limite par message passe de 8 000 à 40 000 caractères (total toujours borné à 48 000) pour qu'un texte source tienne dans un message ; les arguments d'appel d'outil restent à 8 000.
**Conséquences** : l'IA de Flow partage le quota gratuit de Mind (≈ 7 neurons par appel, plus pour une grande source) ; un workflow qui contient un nœud Agent exige un compte ; le déploiement de l'API est nécessaire pour les longues sources.
**Alternatives** : découper la source en plusieurs messages (écarté : plus fragile) ; appels d'outils sans liste blanche (écarté : exécution sans confirmation).
